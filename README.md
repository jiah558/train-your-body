# 体能小屋 · Train Your Body

个人减脂 / 力量打卡站（Rein）。手机浏览器可加到主屏幕。

## 在线

https://jiah558.github.io/train-your-body/

## 功能

- **今日清单**：热量（训练日/休息日）· 蛋白 · 饮水 · 早午晚选菜 · 健身房 A/B/C 组数勾选
- **人体工学**：打开即见下一件待办；大触控区；已完成下沉；四 Tab（今日·训练·体测·我的）
- 小锅小灶菜品库 + 早餐固定选项；全勤印章动画
- 数据仅存本机 `localStorage`

## 本地

直接打开 `index.html`，或任意静态服务器托管本目录。
